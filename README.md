# First month with one teacher — interactive draft

A clickable draft of one flow: what a parent sees when their booked teacher cannot hold a lesson.

Five scenarios in the top rail, plus a switch that changes how far ahead the reschedule search looks.
This is a design draft for discussion — not a shipped product, and not a description of current behaviour.

Live: https://diyoriko.github.io/novakid-teacher-continuity-preview/
